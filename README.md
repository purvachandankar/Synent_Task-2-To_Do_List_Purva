# To-Do List - Python

## 📌 Objective

The objective of this project is to develop a simple **command-line To-Do List application using Python** that allows users to manage their tasks efficiently.

## 🛠️ Tools & Technologies Used

- Python
- Command Line Interface (CLI)
- Python Lists
- Loops and Conditional Statements

## ⚙️ Steps Performed

1. Created an empty list to store tasks.
2. Displayed a menu with options to:
   - Add Task
   - Delete Task
   - View Tasks
   - Exit
3. Implemented the **Add Task** functionality using the `append()` method.
4. Implemented the **Delete Task** functionality using the `remove()` method.
5. Added a check to display **"Task not found"** if the entered task does not exist.
6. Implemented the **View Task** functionality using a `for` loop and `enumerate()` to display tasks with serial numbers.
7. Used a `while` loop to keep the application running until the user selects Exit.
8. Added handling for invalid menu choices.

## ✨ Features

- Add new tasks
- Delete existing tasks
- View all added tasks
- Display tasks with serial numbers
- Handle tasks that are not found
- Interactive command-line menu
- Exit option

## 📊 Outcome

Successfully developed a functional **command-line To-Do List application** using Python. The project provided practical experience with **lists, loops, conditional statements, user input, functions, and basic task management operations**.
